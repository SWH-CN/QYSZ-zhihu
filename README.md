# 清一山长文集
> 「清一山长」知乎公开内容的静态归档站点 · 2021–2026 · 共 2172 篇 · 另含博客专栏 266 章
本仓库是 **清一山长** 在平台发布的公开内容（回答 / 想法 / 文章）的离线归档，并额外收录其「博客全集」按原书目录整理的独立板块。站点使用 [Astro](https://astro.build) 构建为纯静态页面，并通过 GitHub Pages 部署。所有内容仅用于个人学习与资料整理，著作权归原作者所有。
## ✨ 站点特性
- **全文检索**：内置客户端搜索，输入关键词即可快速定位文章
- **多维筛选**：支持按「年份 + 内容类型（回答 / 想法 / 文章）」组合过滤
- **时间线**：首页以「按年份」时间线卡片呈现各年发文量，点击年份卡片直达对应年份的帖子列表；时间线页亦按年份分节
- **标签聚合**：跨年份按主题标签检索
- **分类浏览**：按六大主题分类（人生哲理 / 商业与科技 / 投资理财 / 新教育 / 武术格斗 / 社会与文化）聚合内容，入口 `/categories/`
- **博客专栏**：独立「博客」板块，按原书目录「篇 → 章」组织，共 11 篇、266 章，入口 `/blog/`
- **零后端**：纯静态 HTML，加载快，可离线阅读

│   ├── 2022/
│   ├── ...
│   └── 2026/
├── blog/                   # 博客专栏（按「篇 → 章」组织，11 篇 / 266 章）
│   ├── _articles.json      # 博客目录与元数据
