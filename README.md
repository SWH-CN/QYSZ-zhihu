# 清一山长文集

> 知乎作者「清一山长」公开内容的静态归档站点 · 2021–2026 · 共 2118 篇

本仓库是知乎作者 **清一山长** 在平台发布的公开内容（回答 / 想法 / 文章）的离线归档。站点使用 [Astro](https://astro.build) 构建为纯静态页面，并通过 GitHub Pages 部署。所有内容仅用于个人学习与资料整理，著作权归原作者所有。

## ✨ 站点特性

- **全文检索**：内置客户端搜索，输入关键词即可快速定位文章
- **多维筛选**：支持按「年份 + 内容类型（回答 / 想法 / 文章）」组合过滤
- **时间线**：首页以「按年份」时间线卡片呈现各年发文量，点击年份卡片直达对应年份的帖子列表；时间线页亦按年份分节
- **标签聚合**：跨年份按主题标签检索
- **零后端**：纯静态 HTML，加载快，可离线阅读

## 🗂 目录结构

```
QYSZ-zhihu/
├── index.html              # 首页（按年份时间线卡片，一览各年发文量）
├── tags/                   # 标签筛选页
├── timeline/               # 时间线浏览页
├── search/                 # 全文搜索页
├── posts/
│   ├── 2021/               # 按年份归档
│   │   └── YYYY-MM-DD-标题.../
│   ├── 2022/
│   ├── ...
│   └── 2026/
├── assets/_shared/         # 共享静态资源
├── styles/                 # 样式表
├── _astro/                 # Astro 构建产物
├── sitemap-0.xml           # 站点地图（SEO）
├── sitemap-index.xml
├── favicon.ico / favicon.svg
└── .nojekyll               # 禁用 GitHub Pages 的 Jekyll 处理
```

每篇文章以 `posts/YYYY/YYYY-MM-DD-标题前若干字/` 的目录形式存放，便于按时间回溯。

## 🛠 技术栈

- **框架**：[Astro](https://astro.build)（SSG 静态站点生成）
- **部署**：GitHub Pages（`gh-pages` 分支）
- **检索/筛选**：纯前端实现，无需后端服务

## 🔄 内容更新

站点由知乎导出数据经「Markdown 归档流水线」（如 `markdown-archive-to-site` 类工具）生成并部署。如需补充或更新内容：

1. 将新的知乎内容整理为带元信息的 Markdown（建议包含标题、发布日期、类型、来源链接）；
2. 重新构建站点，生成静态产物；
3. 推送至 `gh-pages` 分支完成部署。
